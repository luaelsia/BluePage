# Blue Page에 기여하기

버그나 개선 아이디어는 GitHub Issue로 알려 주세요. 직접 수정하려면 저장소를 Fork한 뒤 별도 브랜치에서 작업하고 Pull Request를 보내 주세요.

## 개발 환경

- Windows 10/11 x64
- .NET 8 SDK 이상

```powershell
cd src/BluePage
dotnet build -c Release
```

Pull Request에는 변경 이유, 주요 수정 내용과 직접 확인한 테스트를 간단히 적어 주세요. 계정 정보, 토큰, 로그와 개인 문서는 커밋하지 마세요.
