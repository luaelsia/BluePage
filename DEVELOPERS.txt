# Blue Page 개발자 안내

## 요구 사항

- Windows 10/11 x64
- .NET 8 SDK 이상

## 소스 빌드

```powershell
cd src/BluePage
dotnet build -c Release
```

## 배포 파일 생성

```powershell
cd src/BluePage
dotnet publish -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true -p:PublishTrimmed=false -o publish
```

## 로컬 설치

프로젝트 루트에서 실행합니다.

```powershell
.\installer\install.ps1
```
